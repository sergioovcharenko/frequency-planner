# Frequency Planner

Статичний вебзастосунок для налаштування штатних діапазонів керування, вибору ретранслятора та попередньої перевірки дев’яти відеопозицій SA/SB одного комплексу БпЛА.

## Можливості

- штатні діапазони 410–485 і 820–895 МГц;
- захищене підтвердження перед редагуванням;
- матриця SA/SB із дев’яти заводських каналів;
- каталог із 18 альтернативних частот;
- каталог моделей ретрансляторів із посиланнями на джерела характеристик;
- окрема перевірка сумісності відеоканалу з RX ретранслятора;
- розрахунок прямих завад і гармонік лише від TX ретранслятора;
- ручний режим для іншої моделі з довільними RX/TX-частотами й діапазонами;
- блокування повторного призначення частоти;
- локальне збереження та відновлення штатних значень;
- пояснення прямого конфлікту й математично можливих гармонік;
- адаптивний світлий і темний інтерфейс.

## Моделі ретрансляторів

- **Tactical Technology — Repeater on Mavic**: відкриті діапазони керування 433–520, 720–1020 і 2100–2700 МГц; номінальні відеосмуги 5.8/6.5/7.5 ГГц на приймання та 1.2/3.3 ГГц на передавання. [Джерело виробника](https://www.tactech.world/en/products/communication-and-control/repeater).
- **BlueBird Tech — Віщун-5.8**: точний діапазон приймання відео 4990–5945 МГц; передавання оператору 1.2/1.3 ГГц; модуль керування залежить від комплектації. [Джерело виробника](https://www.blue-bird.tech/en/products/wireless-retranslator-blue-bird-repeater/).

RX означає приймання сигналу і не вважається джерелом випромінювання. TX означає передавання та бере участь у перевірці накладань і гармонік. Якщо виробник вказав лише номінальну смугу без точних меж, застосунок показує «Потрібне уточнення».

У режимі «Інша модель» користувач сам додає назву, напрямок RX/TX, призначення каналу та межі в МГц. Усі налаштування зберігаються тільки в локальному сховищі поточного браузера.

## Запуск

```bash
python3 -m http.server 4173
```

Відкрити `http://localhost:4173`.
