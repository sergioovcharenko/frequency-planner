# Frequency Planner

Статичний вебзастосунок для налаштування штатних діапазонів керування та попередньої перевірки дев’яти відеопозицій SA/SB одного комплексу БпЛА.

## Можливості

- штатні діапазони 410–485 і 820–895 МГц;
- захищене підтвердження перед редагуванням;
- матриця SA/SB із дев’яти заводських каналів;
- каталог із 18 альтернативних частот;
- блокування повторного призначення частоти;
- локальне збереження та відновлення штатних значень;
- пояснення прямого конфлікту й математично можливих гармонік;
- адаптивний світлий і темний інтерфейс.

## Запуск

```bash
python3 -m http.server 4173
```

Відкрити `http://localhost:4173`.

## Тести

```bash
node --test
```

## Важливо

Застосунок виконує попередній математичний аналіз. Він не вимірює реальну потужність паразитних випромінювань і не замінює перевірку обладнання спектроаналізатором.
