# ZOOM-D Dark Theme Design

## Мета

Оформити весь Frequency Planner у візуальному стилі калькулятора ZOOM-D: темний графітовий інтерфейс із помаранчевим акцентом, великими полями та чіткими кольорами статусів.

## Межі зміни

- Змінюється лише HTML-мета теми та CSS.
- Алгоритми аналізу, профілі, каталог ретрансляторів і локальне збереження не змінюються.
- Тема постійно темна на Android, iOS, планшеті й комп'ютері.
- Матриця каналів зберігає горизонтальне прокручування на вузьких екранах.

## Візуальна система

| Роль | Колір |
|---|---|
| Фон сторінки | `#080b0f` |
| Основна поверхня | `#11161c` |
| Поле/вкладена поверхня | `#1d242d` |
| Основний текст | `#f4f7fb` |
| Другорядний текст | `#9cabbc` |
| Акцент | `#ff6a00` |
| Підходить | `#00d67a` |
| Обережно | `#ffc247` |
| Можлива завада | `#ff8a1f` |
| Небезпечно | `#ff4d4f` |

Активні кнопки й заголовки використовують помаранчевий акцент. Зеленим позначаються лише позитивні/безпечні стани, щоб акцент інтерфейсу не змішувався зі статусом сумісності.

## Адаптивність і доступність

- Мінімальна ширина підтримки — `320px`.
- Інтерактивні елементи мають висоту не менше `44px`.
- Фокус клавіатури має виразний помаранчевий контур.
- Колір кожного статусу дублюється текстом.
- Наявні брейкпойнти `760px` і `430px` зберігаються.
